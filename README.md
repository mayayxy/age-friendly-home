# 安居适老助手（网页版）

帮助有老人的家庭快速发现居家安全隐患，并给出适老化改造建议。

## 如何打开

直接用浏览器打开根目录下的 `index.html` 即可，无需安装依赖。

也可以在本目录启动本地服务：

```bash
npx --yes serve .
```

然后访问提示的本地地址。

## 当前能力

- 拍照或上传家中图片
- 选择空间类型：卫生间、卧室、客厅、厨房、走廊/玄关
- 输出安全评分、风险点和改造建议

## 说明

当前为演示版：风险结果按所选空间类型模拟生成，尚未接入真实图像识别。
